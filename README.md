# Aurora Post Privacy Policy

Static multilingual privacy-policy site prepared for GitHub and Vercel.

Replace in `index.html` before deployment:

- `DEVELOPER_OR_COMPANY_NAME`
- `PRIVACY_EMAIL`
- `PUBLICATION_DATE`
- `APP_WEBSITE_URL`

The text is a practical publication template and not a substitute for legal advice. Keep it synchronized with the actual SDKs, target audience and store disclosures.

Vercel settings: Framework Preset **Other**, Root Directory `./`, Build Command empty, Output Directory `./`.
